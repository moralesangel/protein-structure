How it works

1 · GraphEach residue is a node at its Cα; edges join residues within 8 Å.
2 · FeaturesResidue chemistry, plus six geometric features describing the local pocket shape.
3 · Message passingFour distance-aware layers mix each residue with its spatial neighbours.
4 · ScoreA head outputs one binding probability per residue.

Training used focal loss because only about 7% of residues contact a ligand, and the checkpoint was selected on validation PR-AUC rather than accuracy — with a base rate that low, a model predicting "never" would still score 93% accurate.

The structures are drawn by Mol*, the viewer behind the RCSB PDB site and the AlphaFold database. Each prediction travels in the B-factor column of the PDB file — the same column AlphaFold uses for pLDDT — so the colouring is the viewer's own rather than something bolted on.
